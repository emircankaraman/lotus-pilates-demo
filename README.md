# Lotus Pilates

Küçük gruplarla reformer ve mat pilates. Duruşunu düzelt, esnekliğini artır, kendine zaman ayır.

**Durum:** Hayalî örnek site (şablonun klasik düzeni ve 'zarif' teması). Bilgiler gerçek değildir.

## Görüntüleme
`index.html` dosyasını tarayıcıda açmak yeterli. Site tamamen statiktir; Netlify, Cloudflare Pages veya GitHub Pages'e olduğu gibi yüklenebilir.

## Düzenleme
Bu depodaki dosyaları elle değiştirme. Site, gizli **site-sablonu** deposundaki `musteriler/lotus-pilates/ayarlar.json` dosyasından üretilir:

```bash
cd site-sablonu
./depoya-gonder.sh lotus-pilates
```
